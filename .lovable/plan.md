# תכנית עבודה — עיצוב מחדש של Sweetbaby

מיישם את המפרט המלא: פלטת פודרה/ירוק, טופס פתיחה חובה, שני מסלולי הזמנה, לוגיקת מלאי, מקדמות, חריגות זמן וביטולים.

## 1. עיצוב מחודש (design tokens)

עדכון `src/styles.css`:
- רקע: `--background` פודרה רך (`oklch(0.96 0.02 20)`)
- primary: ירוק כהה יוקרתי מהלוגו (`oklch(0.32 0.05 155)`)
- accent: פודרה עמוקה לכפתורים/הדגשות
- כרטיסים שקופים/זכוכית עם `backdrop-blur`
- כותרות בירוק, גופים בפודרה — כפתורי CTA בירוק בולט
- שמירת פונטים ו-RTL הקיימים

## 2. שינויים במסד הנתונים (מיגרציה אחת)

- `bookings` — טבלה חדשה לשריון סטודיו: `start_at`, `end_at`, `slots` (חצאי שעות), `package` (regular/morning), `hours_total`, `price`.
- `orders`: הוספת שדות `track` (studio/props), `deposit_amount`, `deposit_status`, `deposit_receipt_url`, `balance_method` (cash/transfer/bit/paybox), `balance_amount`, `camera_model`, `session_date`, `overtime_minutes`, `overtime_charge`, `cancellation_charge`, `terms_accepted_at`.
- `items`: הוספת `stock_quantity` (ברירת מחדל 1).
- `item_availability` — טבלה: `item_id`, `date`, `order_id` — מונעת כפילות ליום.
- `leads` — טופס פתיחה: email, full_name, phone, referral_source.
- Storage bucket `receipts` להעלאת אסמכתאות.
- GRANTs + RLS מלאים.

## 3. זרימת משתמש חדשה

**דף בית → טופס הפתיחה החובה** (`/start`):
- שדות: email, שם מלא, טלפון, "איך הגעתם אלינו?" — כולם חובה
- נשמר ב-`leads`, ואז מציג בחירת מסלול

**בחירת מסלול** (`/track`):
- כרטיס א': שריון סטודיו → `/booking`
- כרטיס ב': השכרת אביזרים → `/catalog`

## 4. מסלול א' — שריון יומן (`/booking`)

- בחירת תאריך (חסימת ימים לא זמינים)
- Grid חצאי שעות לפי שעות הפעילות:
  - א'-ה' 08:00–23:00
  - ו'/ערבי חג 08:00 עד שעתיים לפני שבת (חישוב לפי `hebcal` API או קלט ידני של אדמין)
  - מוצ"ש שעה אחרי צאת השבת
- מינימום 2 חצאי שעות (שעה)
- תמחור:
  - שעה ראשונה 120₪, כל נוספת 90₪, חצאי שעות יחסית
  - חבילת בוקר: 08:00–13:00, 3 שעות = 240₪ (זיהוי אוטומטי)
- כפתור "המשך לתשלום מקדמה"

## 5. מסלול ב' — אביזרים (`/catalog` → `/cart` → `/checkout`)

- בקטלוג: הצגת "לא זמין ב-DD/MM" לפי `item_availability`
- הוספת שדה `session_date` ("מתי נתראה?") לפני הוספה לסל
- שדה חובה בצ'קאאוט: `camera_model`
- מינימום סל 50₪
- בשליחת הזמנה: `INSERT` ל-`item_availability` לכל פריט+תאריך (unique constraint מונע כפילות)

## 6. תשלום מקדמה (עמוד חדש `/deposit/:orderId`)

- הצגת פרטי חשבון: בנק 12, סניף 533, חשבון 648912, מיכל סיבוני
- מקדמה 90₪ (או 100% אם הזמנה להיום)
- העלאת אסמכתא → `receipts` bucket
- בחירת אופן תשלום יתרה (cash/transfer/bit/paybox) + סכום יתרה
- checkbox "אני מאשרת את תנאי הסטודיו" עם טקסט מלא (30 יום אבדות, ניקיון 150₪, חשמל 7₪/שעה, רקעי נייר, אחריות נזקים, שירותים קומה 5 דירה 18)
- שליחת מייל לסטודיו עם אסמכתא + פרטי הזמנה

## 7. אוטומציות אדמין (server functions בלבד — לא מיישם UI SMS בשלב זה)

- `computeOvertime(orderId, actualEndAt)`: 15–44 דק' = חצי שעת חיוב, 45+ = שעה מלאה. מעדכן `overtime_charge`.
- `cancelOrder(orderId, sameDay)`: לפני יום האירוע = מקדמה לא מוחזרת. ביום עצמו = 100% חיוב.
- לוח האדמין הקיים (`/admin/calendar`) יציג גם `bookings` וגם `orders`.

## 8. תבניות SMS

מפרט תבניות ההודעות עצמן (הודעת סיכום עם כללי הסטודיו) — אשאיר לסיבוב הבא כפי שהמשתמשת שאלה בסוף. כרגע ההודעה תישלח כמייל בעברית עם כל הכללים.

## 9. סדר יישום

1. מיגרציה + RLS + storage bucket
2. עדכון `styles.css` לפלטה החדשה
3. `/start` + `/track` (טופס פתיחה + בחירת מסלול)
4. `/booking` (יומן חצאי שעות + תמחור)
5. עדכון קטלוג/סל/צ'קאאוט עם תאריך+מצלמה+חסימת מלאי
6. `/deposit/:id` + העלאת אסמכתא + מייל
7. סרבר-פונקציות: overtime + cancellation
8. עדכון פאנל אדמין להצגת bookings, מקדמות, אסמכתאות

## הערות טכניות

- שעות שבת/חג: לגרסה ראשונה — קלט ידני של אדמין (`studio_closures` table) עם שעת סגירה/פתיחה לתאריך ספציפי; אינטגרציה עם hebcal בעתיד.
- מייל: דרך Lovable Emails (יצריך `setup_email_infra` — אבקש אישור בהמשך).
- העלאת אסמכתא: `storage.upload` מהלקוח לתוך bucket `receipts` פרטי, RLS לפי `user_id`.

מאשרת ואני מתחיל להטמיע? אם יש שינויים/עדיפויות אחרות (למשל דלג על אוטומציות ותתמקד בטופס+יומן+מקדמה) — כתבי לי.
