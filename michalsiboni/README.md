# אתר מיכל סיבוני (michalsiboni.co.il) — ייצוא וורדפרס

תיקייה נפרדת מקוד Sweet Baby Studio. מכילה את תוכן הטקסט שחולץ מקובץ ייצוא
WordPress (WXR, 2026-10-07): 14 עמודים, 5 פוסטים (המלצות), 8 פריטי בלוג.

- `content/*.md` — קובץ לכל עמוד/פוסט. טקסטים בלבד (מ-Elementor / תוכן רגיל), ללא עיצוב.
- `extract-wxr.py` — הסקריפט שחילץ אותם: `python3 -I extract-wxr.py <export.xml> <out-dir>`.

- `original/` — קובץ הייצוא המקורי המלא (כולל תפריטים, CSS, הגדרות).
- `elementor/*.json` — מבנה Elementor המלא של כל עמוד/תבנית.
- `images.tsv` — 637 כתובות התמונות המקוריות (התמונות עצמן לא הועתקו, רק קישורים).
