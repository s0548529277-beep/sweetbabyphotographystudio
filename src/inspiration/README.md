# Inspiration Images

Drop images here named by SKU and they show up automatically:

- `sku-123.jpg` or `sku-123-2.jpg`, `sku-123-3.jpg` — inspiration for prop with SKU 123 (shown in /rental-catalog item card, /items/:id, and popover)
- `studio-1.jpg`, `studio-2.jpg` — inspiration for the studio itself (shown in /studio-rental)

Formats supported: .jpg .jpeg .png .webp .avif
